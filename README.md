Ручное тестирование REST API метода **создания организации**.

**Эндпоинт:** `POST /api/v1/de/organization`  
**Фокус:** валидация полей, авторизация, бизнес-логика ИНН/ОГРН, граничные значения, негативные сценарии.

---

## О проекте

Проект выполнен как тестовое задание на позицию Junior/Intern QA.  
Цель — проверить метод создания организации по документации (схема запроса, таблица валидации, алгоритм).

### Что проверялось

| Область | Что сделано |
|--------|-------------|
| Авторизация | Bearer-токен: отсутствие → 401, невалидный токен |
| Позитивные сценарии | Успешное создание с ИНН 10 и 12 цифр |
| Обязательность полей | Отсутствие / пустые значения обязательных полей |
| Граничные значения | min−1 / min / max / max+1 по длине полей |
| Форматы | ИНН (только цифры, 10/12), ОГРН (13 цифр), телефон |
| Бизнес-логика | ОГРН обязателен при ИНН из 10 цифр; уникальность ИНН |
| Расхождения с документацией | Зафиксированы несоответствия таблицы валидации и алгоритма |

## Структура коллекции Postman

```text
API Organization
├── Авторизация
│   ├── Получение токена
│   ├── Без токена → 401
│   └── Невалидный токен
├── Позитивные сценарии
│   ├── ИНН 10 цифр + ОГРН
│   └── ИНН 12 цифр (ОГРН не обязателен)
└── Негативные / валидация
    ├── name, address, head (firstName, lastName)
    ├── inn (длина, формат, уникальность)
    ├── ogrn (длина, формат, обязательность при ИНН 10)
    └── phone (формат)
```

---

## Подход к тест-дизайну

- **Классы эквивалентности** — валидные / невалидные наборы значений  
- **Граничные значения** — длина строк и количество цифр  
- **Негативные сценарии** — обязательность, форматы, бизнес-правила  
- **Проверка статусов** — 200, 400, 401 (и зафиксированное поведение 500 на невалидном токене)

---

## Найденные особенности / расхождения

1. **ОГРН и ИНН**  
   По алгоритму: при ИНН из 10 цифр ОГРН обязателен; при ИНН из 12 — нет.  
   Часть поведения расходилась с таблицей валидации в документации — зафиксировано в тестах.

2. **Невалидный токен**  
   В части случаев возвращался 500 вместо ожидаемого 401 — отмечено как дефект/несоответствие.

3. **Уникальность ИНН**  
   Повторное создание организации с тем же ИНН → 400 «Организация уже зарегистрирована».
